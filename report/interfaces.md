# 接口说明

| 接口 | 用途 |
|---|---|
| USB UVC | 左右拼接双目图像采集 |
| 串口，115200 | 环境启动与诊断 |
| PS_ETH | 电脑与板卡之间的模型及结果传输 |
| 127.0.0.1:8849 | 本地网页与任务接口 |
| 板卡端口 8788 | 相机、预览、HDMI 与按键服务 |
| 板卡端口 8850 | 推理服务 |
| 板卡端口 8852 | PL 截面会话 |
| 板卡端口 8853 | 拍照、保存帧输入及显示扩展 |
| 本地端口 8860 | 启动器控制接口，凭据认证 |

## 网络

电脑地址为 `192.168.137.1/24`，板卡地址为 `192.168.137.2/24`。

`GET /api/status` 查询状态，`POST /api/capture` 触发拍照。请求格式及状态码见 `src/host/app/host.py`。

## 坐标接口

FGP1 控制基址为 `0xA10C0000`，专用 DDR 为 `0x67000000–0x67400000`。输入为 FP32 视差及 FP64 Q 矩阵，输出为 FP32 XYZ、深度及有效位。图像数组采用高×宽的维度顺序。

其他寄存器与 DDR 布局见对应模块配置和原生驱动。访问前应确认当前装载的 PL 配置及预留内存范围。

## 任务交接

1. 获取当前任务与配置状态。
2. 等待 DMA 完成后释放数据映射。
3. 在调度交接点切换配置并恢复生产者。
4. 通过任务编号拒绝过期结果。
5. 超时或所有权不明时保留故障锁、日志和快照，按恢复流程处理。
