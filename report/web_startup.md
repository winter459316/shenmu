# 网页启动与故障排查

## 工作方式

浏览器访问电脑上的 Python 服务 `http://127.0.0.1:8849/`。该服务通过以太网与板卡 `192.168.137.2` 通信，组织拍照和重建任务、接收结果并提供模型文件。浏览器使用 WebGL 2 显示三维模型和截面，显示画面可同步至 HDMI。

立体匹配由板端 PS/PL 协同执行；网页负责交互与显示。换电脑使用时，应先在目标电脑安装并启动本项目。

## 启动步骤

1. 首次使用运行 `setup.cmd`。
2. 在 `.runtime/zu4ev_stereo/launcher/config.json` 配置串口，设置电脑有线网卡为 `192.168.137.1/24`。
3. 刚上电且原厂 Linux 空闲的板卡运行 `cold_start.cmd`；运行环境已准备时使用 `start.cmd`。
4. 运行 `open_web.cmd`，访问 `http://127.0.0.1:8849/`。
5. 运行 `status.cmd` 检查服务状态。

## 命令

| 入口 | 用途 |
|---|---|
| setup.cmd | 安装运行文件及依赖 |
| open_web.cmd | 启动或复用本包电脑端服务并打开页面 |
| start.cmd | 启动电脑端并准备实时服务 |
| status.cmd | 查看网页与板端服务状态 |
| diagnose.cmd | 只读检查配置、端口和板端连接 |
| cold_start.cmd | 准备刚上电、原厂 Linux 空闲状态的板卡 |
| stop.cmd | 关闭本包管理的空闲电脑端服务 |

## 故障处理

| 现象 | 处理步骤 |
|---|---|
| 浏览器无法连接本机地址 | 首次使用执行 setup.cmd，再运行 open_web.cmd |
| 8849 端口被其他目录占用 | 从该服务所属目录运行 stop.cmd，再启动本项目 |
| 页面打开但无实时画面 | 运行 diagnose.cmd，检查供电、网线、地址及板端服务 |
| 板端部分服务未就绪 | 根据诊断定位对应服务；保留日志，按恢复流程处理 |
| 三维区域不显示 | 启用浏览器 WebGL 2，使用固定的 127.0.0.1 地址访问 |
| 文件或配置校验失败 | 核对完整包与资产版本，重新准备匹配文件 |

## 日志位置

日志位于 `.runtime/zu4ev_stereo/launcher/logs`：

- `diagnosis.json`：诊断结果。
- `host_stderr.log`：电脑端服务错误。
- `entry_error.log`：启动入口错误。

存在 DMA 故障锁或未完成的切换快照时，应先检查任务与硬件状态，再按恢复流程处理。
