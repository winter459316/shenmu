# 运行资源

本目录提供完整运行所需的模型、原生库、标定参数、离线依赖及参考样例。目录名称用于兼容安装脚本；本目录中的内容可随本仓库获取。

## 文件

- runtime_assets.part001 等：运行资产分卷。
- asset_parts.json：分卷顺序、大小及校验值。
- wheels：电脑端 Python 离线依赖。
- sample：保存数据样例。
- model_license.txt：模型原有许可。

## 安装

1. 克隆完整仓库，保持本目录位于项目根目录。
2. 安装 Python 3.12 x64 和串口驱动。
3. 在项目根目录运行 setup.cmd。安装器自动检查并合并分卷，然后建立运行环境。
4. 在 .runtime/zu4ev_stereo/launcher/config.json 配置实际串口。
5. 按项目 README 连接板卡并启动。

不要单独下载某一个分卷。合并后的缓存位于 .runtime/cache，不提交到仓库。运行配置使用公开演示访问码，适用于隔离的板卡直连演示；不包含原开发板的访问码。全新板卡的厂商 Linux 基础系统需单独准备。
