# 硬件连接与配置

## 设备

- 正点原子 MPSoC-P4 V1.7 开发板，核心器件 XCZU4EV。
- 双目 USB 摄像头、串口线、以太网线、HDMI 显示器及配套电源。
- 配套 AArch64 Linux 基础系统。应用包不包含整张 SD 系统镜像。

## 连接步骤

1. 将双目摄像头连接到开发板 USB 接口。
2. 将电脑有线网口连接到开发板 PS_ETH 接口。
3. 将串口连接到电脑，并在设备管理器确认端口号；串口波特率为 115200。
4. 连接 HDMI 显示器并接通开发板电源。
5. 将电脑网卡设置为 `192.168.137.1/24`，板卡设置为 `192.168.137.2/24`。
6. 在电脑运行 `setup.cmd`，随后在 `.runtime/zu4ev_stereo/launcher/config.json` 配置串口号。
7. 按 [复现手册](../report/reproduction.md) 启动系统。

板端应用使用 Python 3.7.6、NumPy 1.21.6、ORT 1.14.1 及配套原生库。电脑端使用 Python 3.12 x64。
