# 模型与计算配置

模型名称、来源及版本见 `model_manifest.json`。

| 项目 | 配置 |
|---|---|
| 单眼网络输入，宽×高 | 320×360 |
| 内部补齐尺寸，宽×高 | 320×384 |
| 迭代次数 | 2 |
| 最大视差参数 | 192 |
| PL2 主要卷积 | INT16 乘法、INT48 累加 |
| PL2 反卷积 | FP32 |
| PL3 三维卷积 | 3 个选定节点，FP32，44 路并行 |

其余网络运算由 A53 执行，电脑端负责三维组织与显示。模型和原生库通过配套资产目录安装；文件大小与校验值见 `board/config/runtime_assets.json`。
