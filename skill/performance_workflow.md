# 性能与资源比较流程

适用于可以固定输入、模型、精度和执行配置的工程比较。

## 操作步骤

1. 固定参考输入、模型版本、迭代次数、精度及线程策略，并记录输入校验值。
2. 分别定义核心计算、网络前向、板端处理、电脑渲染及 HDMI 显示的计时范围。
3. 为参考方案和对照方案设置相同运行条件，交替采样并保留原始测量值。
4. 每次测量同时检查数值输出和服务恢复状态。
5. 统计样本数、中位数与波动范围。
6. 对比 LUT、FF、DSP、BRAM、URAM、时钟与建立及保持裕量。
7. 将输入条件、时间范围、数值比较和资源数据放在同一结果表中。

## 比较条件

输入、分辨率、精度、迭代次数及计时范围必须一致。不同阶段存在包含或重叠关系时，分别统计，不直接累加。跨工具版本的数据应标明版本。
