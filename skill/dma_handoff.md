# DMA 与配置交接流程

适用于具有完成状态、可停止输入且支持独占资源访问的 FPGA 加速器。

## 操作步骤

1. 查询任务编号和软件状态，确认无并发任务。
2. 获取完整事务的使用权，停止或冻结输入，等待 DMA 完成。
3. 由所属驱动读取完成位；外部监视使用软件诊断接口。
4. 核对预留 DDR、地址范围、对齐、缓存属性及当前配置。
5. 确认空闲后释放映射并切换配置。
6. 重建驱动状态，确认新配置，再恢复输入。
7. 观察新任务或新帧，随后开放按键与显示请求。
8. 超时保留故障锁、日志和快照，定位原因后执行恢复。

## 使用条件

跨板使用应重新声明寄存器、总线宽度、复位极性和内存地址。完成信号不明确、缓存所有权未定义或 DDR 与 Linux 内存重叠时，不执行配置切换。
